How the value is computed

No protocol name is ever special-cased. The same formula scores every row, from the snapshot's own figures only.

Category multiples — read off this snapshot's live tokens

Each multiple is the median market-cap-to-TVL ratio of the live-token protocols in that category (three or more of them, else the snapshot's overall median), clamped to 0.05–0.80. A DEX is priced off live DEXs, a lender off live lenders.
